DIOS (Domain Investing Operating System): The Due-Diligence Workflow

DIOS is the gate-and-score framework built for Domain Decoded — a binary reject gate followed by an 11-factor weighted score. Every domain in the portfolio passes through it before acquisition — no exceptions.

What Is DIOS?

DIOS stands for Domain Investing Operating System — a personal framework built by Imteaz (Galib) Chowdhury for Domain Decoded, used to gate and score every name before it's added to the portfolio. It runs in two layers: a binary reject gate that checks trademark conflict, UDRP history, Wayback Machine history, phonetic collision with existing brands, portfolio cannibalization, and negative semantic load in other languages — failing any one of these gets a domain rejected outright, no score attached. Names that clear the gate move into an 11-factor weighted score covering brandability, comparable sales, search volume, niche relevance, and more, split across two tracks — Track B for brandable/coined names and Track D for descriptive/category names.

Even with DIOS in place, every result is still manually verified against USPTO/TESS and Trademarkia before a domain is priced — the framework narrows the field, it doesn't replace the final check.

The Five-Stage Workflow

1
Brainstorm & Shortlist
Generate 15–20 candidate names built around the target niche, category signal, and tone.
Output: Raw candidate list
2
Trademark & USPTO Clearance
Every candidate checked against Trademark and USPTO TESS for existing conflicts.
Active trademark conflicts rejected
3
Wayback Machine History Audit
Ruled out any name with old spam history, adult content, or brand damage from a previous owner. A name with a real past is not hidden: the scholarship case study shows how that is disclosed up front.
Unclean history rejected
4
Comparable-Sales Valuation
NameBio data used to benchmark fair value against similar LegalTech/FinTech/brandable sales.
Priced outside fair value range rejected
5
Radio Test & Final Decision
Final candidates spoken aloud to test pronunciation, spelling, and 24-hour memorability.
Approved → added to portfolio
Only the strongest names make it through. Every domain in the portfolio has passed every test.
