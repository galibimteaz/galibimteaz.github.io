Naming Decision File · Case 006

How "SanaGrid" Was Derived, Not Invented

A name isn't picked from a list. It's grown from a root concept, tested branch by branch, and pruned until one path survives. Here is the actual tree behind SanaGrid.com.

Category
Healthcare Network / HealthTech Infrastructure
Emotional Target
Trust, Stability, Systemic Intelligence
Constraint
.com available, 10 letters, no hyphenation

Root Concept

"A network you can trust with health data"

Branch A — Health Root

  • Sana — Latin: healthy
  • Vita — rejected: overused in wellness naming
  • Cura — rejected: too clinical, hard to brand

Branch B — Systems Root

  • Grid — signals infrastructure, engineering
  • Mesh — rejected: overused in tech naming
  • Nexis — rejected: trademark conflict risk
Combination Test: SanaGrid — "Healthy" + "Grid": systemic, clear, unpatented

Screening Results

  • Pronunciation (radio test) Pass
  • USPTO / Trademark conflict Clear
  • .com availability Available
  • Wayback history Clean
  • Category fit (health + systems) Strong

Final Selection

SanaGrid.com
"Better Health. Smarter Systems."

The only branch that survived every filter: a health-tech root soft enough for humans, a systems suffix strong enough to signal infrastructure — without becoming an overused wellness or tech cliché.
